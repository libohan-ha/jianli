## 3. 路由设计

### 3.1 路由表

| 路径          | 页面          | 描述        | 参数            |
| ------------- | ------------- | ----------- | --------------- |
| `/`           | HomePage      | 首页/上传页 | -               |
| `/analyzing`  | AnalyzingPage | 分析进度页  | -               |
| `/result/:id` | ResultPage    | 分析结果页  | id: 分析记录 ID |
| `/diff/:id`   | DiffPage      | Diff 对比页 | id: 分析记录 ID |
| `/export/:id` | ExportPage    | 导出预览页  | id: 分析记录 ID |

### 3.2 路由流程

```
/（首页）
    │
    ├─── 上传文件/输入文本
    │
    ▼
/analyzing（分析中）
    │
    ├─── 分析完成后自动跳转
    │
    ▼
/result/:id（结果页）
    │
    ├─── 点击"查看详细对比"
    │           │
    │           ▼
    │    /diff/:id（Diff对比页）
    │           │
    │           ├─── 点击"导出"
    │           │
    │           ▼
    │    /export/:id（导出预览页）
    │
    └─── 点击"重新分析" → 返回 /
```

## 6. 状态管理

### 6.1 全局状态结构

使用 Zustand 进行状态管理，主要 Store 结构：

#### AppStore (全局应用状态)

```
{
  // 用户信息
  user: {
    isLoggedIn: boolean
    userInfo: UserInfo | null
  }

  // 加载状态
  loading: {
    global: boolean
    upload: boolean
    analysis: boolean
  }
}
```

#### AnalysisStore (分析相关状态)

```
{
  // 当前分析会话
  currentSession: {
    id: string | null
    status: 'idle' | 'uploading' | 'analyzing' | 'completed' | 'error'
    progress: number                // 0-100
    currentStep: string             // 当前步骤描述
  }

  // 原始输入
  originalContent: {
    type: 'file' | 'text'
    fileName: string | null
    content: string
  }

  // 分析结果
  result: {
    overallScore: number
    dimensions: DimensionScore[]
    problems: Problem[]
    suggestions: Suggestion[]
    optimizedContent: string
  } | null

  // Diff状态
  diff: {
    changes: Change[]               // 所有变更
    acceptedChanges: string[]       // 已采纳的变更ID
  }

  // 导出配置
  export: {
    format: 'pdf' | 'markdown'
    template: string
    fileName: string
  }
}
```

### 6.2 数据流向

```
用户操作
    │
    ▼
Action (状态更新函数)
    │
    ▼
Store State (状态存储)
    │
    ▼
Component (组件订阅并渲染)
```

## 7. 接口对接规范

### 7.1 API 基础配置

```
Base URL: /api/v1
超时时间: 30秒 (分析接口60秒)
内容类型: application/json
文件上传: multipart/form-data
```

### 7.2 需要对接的后端接口

| 接口     | 方法 | 路径                     | 功能            | 对应页面 |
| -------- | ---- | ------------------------ | --------------- | -------- |
| 上传文件 | POST | `/upload`                | 上传 PDF 并解析 | 首页     |
| 开始分析 | POST | `/analysis/start`        | 启动 AI 分析    | 首页     |
| 查询进度 | GET  | `/analysis/:id/progress` | 获取分析进度    | 分析页   |
| 获取结果 | GET  | `/analysis/:id/result`   | 获取分析结果    | 结果页   |
| 采纳修改 | POST | `/analysis/:id/accept`   | 采纳优化建议    | Diff 页  |
| 导出 PDF | GET  | `/export/:id/pdf`        | 生成 PDF 文件   | 导出页   |
| 导出 MD  | GET  | `/export/:id/markdown`   | 生成 Markdown   | 导出页   |

### 7.3 接口请求/响应格式

#### 上传文件

```
请求:
  POST /api/v1/upload
  Content-Type: multipart/form-data
  Body:
    - file: PDF文件

响应:
  {
    "code": 200,
    "data": {
      "fileId": "file_xxx",
      "fileName": "简历.pdf",
      "content": "提取的文本内容...",
      "pageCount": 2
```

### 7.4 错误处理

前端需要处理的错误码：

| 错误码 | 含义            | 前端处理               |
| ------ | --------------- | ---------------------- |
| 400    | 请求参数错误    | 提示用户检查输入       |
| 401    | 未登录/登录过期 | 跳转登录页             |
| 413    | 文件过大        | 提示文件大小限制       |
| 415    | 文件格式不支持  | 提示支持的格式         |
| 429    | 请求过于频繁    | 提示稍后重试           |
| 500    | 服务器错误      | 提示系统繁忙           |
| 503    | AI 服务不可用   | 提示 AI 服务暂时不可用 |
